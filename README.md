# 校园在线考试与自动评卷系统 v4

## 项目信息
- **项目名称**：校园在线考试与自动评卷系统
- **参赛学院**：数据产业学院

## 快速开始
1. 直接用浏览器打开 `index.html` 文件即可使用
2. 教师登录：admin / admin123
3. 学生需要先注册账号

## 功能清单

### 1. 账号系统 ✓
- [x] 学生/教师双身份注册登录
- [x] localStorage持久化数据存储
- [x] 预设教师账号：admin / admin123

### 2. 题型支持 ✓
- [x] 单选题
- [x] 多选题
- [x] 判断题
- [x] 填空题
- [x] 简答题

### 3. 考试功能 ✓
- [x] 多科目支持（数学、语文、英语、物理、化学）
- [x] 智能组卷（随机抽取题目）
- [x] 限时答题（倒计时）
- [x] 答题卡导航

### 4. 防作弊功能 ✓
- [x] 切屏检测
- [x] 复制粘贴防护
- [x] 作弊行为记录

### 5. AI评分 ✓
- [x] 自动批改客观题
- [x] 简答题关键词评分

### 6. 成绩统计 ✓
- [x] 个人成绩、排名
- [x] 教师端班级分析
- [x] ECharts图表可视化

### 7. 教师端 ✓
- [x] 题库管理（增删改查）
- [x] 试卷管理（创建/删除）
- [x] 成绩管理（查看/筛选）

### 8. 学生端 ✓
- [x] 考试中心（查看/参加考试）
- [x] 成绩查询（成绩趋势图）

## 技术特点
- 纯原生 HTML/CSS/JavaScript 开发
- 无需后端，localStorage 数据持久化
- ECharts 图表可视化
- 响应式设计
- 所有代码集成在单个HTML文件中
